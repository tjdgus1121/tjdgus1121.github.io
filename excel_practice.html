      전체 선택

      1단계 아직 완료되지 않음

      셀 다루기

      • 칸을 누르고 바로 입력 · F2 고쳐 쓰기
      • Enter 아래로 · Tab 오른쪽으로
      • Delete 내용 지우기
      • 열 문자·행 번호를 누르면 그 줄 전체 선택
      • 머리글 경계선을 끌면 너비·높이 조절

      수식

      • 계산은 = 로 시작 · =SU 까지 치면 함수 목록이 뜸
      • 쓸 수 있는 함수: SUM AVERAGE MAX MIN COUNT COUNTA ROUND
      • 숫자 아래 칸에서 Σ 자동 합계(Alt+=) → 범위를 알아서 잡아 줌
      • 수식 중에 칸을 클릭·드래그하면 주소가 저절로 들어감
      • 닫는 괄호는 빠뜨려도 자동으로 채워짐
      • F4 로 $ 고정 (절대참조)
      • 범위 선택 후 Ctrl+Enter → 선택한 칸 전체에 입력

      복사 · 붙여넣기

      • Ctrl+C 복사 · Ctrl+X 잘라내기 · Ctrl+V 붙여넣기
      • Ctrl+Alt+V 선택하여 붙여넣기 (값만·행열 바꿈)
      • 오른쪽 버튼을 누르면 삽입·삭제 메뉴 (터치는 길게)
      • 복사 직후 Ctrl+Z 또는 Esc → 복사 취소

      표시 형식

      • 쉼표 1234 → 1,234
      • 백분율 0.85 → 85%
      • 자릿수 늘림·줄임으로 소수점 조절
      • 보이는 모습만 바뀌고 값은 그대로입니다

      되돌리기 · 저장

      • Ctrl+Z 되돌리기 · Ctrl+Y 다시 실행
      • 입력한 내용은 이 컴퓨터에 자동 저장 (새로 고쳐도 남음)
      • 지우려면 시트 초기화

      이름 상자 · 시트

      • 왼쪽 위 칸에 A2:C5 → 그 범위 선택
      • 다른 시트는 정리!B2 처럼 시트 이름과 !
