사진에 정답 상자와 이름을 붙여요

활동 순서 보기

    사진 준비

    어떤 사진으로 시작할까요?

    사진은 이 기기에서 처리해요

    아직 올린 사진이 없습니다.

    처음이라면 연습 사진부터 시작하세요. 정답 상자와 이름표는 직접 붙입니다.

    사진 준비와 파일 다운로드 안내

    이름 2개에 각각 최소 3장씩 정답을 표시하면 첫 학습을 시작할 수 있어요. 더 잘 찾게 하려면 이름마다 10장 이상, 배경이 다양한 사진을 모아요. ‘시험_’ 사진은 5단계에서 사용해요.

    수업용 묶음(3MB) · 전체 묶음(14MB)을 파일로 받을 수도 있어요.

      이름표

      최대 7개

      이름은 7개까지 만들 수 있습니다. 쓰지 않는 이름은 ×로 지울 수 있습니다.

      사진 위에 정답 그리기

      이름 선택 → 상자 그리기

      이름을 고르고, 사진 위를 끌어 상자를 그려요.

      키보드 단축키숫자 1~7 이름 고르기 · ←/→ 사진 넘기기 · F 사진 전체를 상자로 · N 상자 고르기 · 상자를 고른 뒤 방향키로 옮기고 Shift+방향키로 크기 조절 · Delete 지우기 · Esc 고르기 취소
      생각해 보기

      상자의 중심이 들어 있는 칸 하나가 그 물체를 “책임”집니다. 나머지 칸은 “여기엔 없다”고 답하도록 배웁니다. 한 사진에서 ‘없다’를 배우는 칸과 ‘있다’를 배우는 칸 중 어느 쪽이 더 많을까요?

      내 사진 목록

      정답 표시 저장·불러오기

      표시는 자동 저장되지만 학교 컴퓨터는 지워질 수 있어요. 파일로도 저장하세요. 모둠원 파일을 불러오면 합쳐져요.

      내 사진을 MobileNet의 눈으로 보기

      사진 120만 장으로 보는 법을 익힌 MobileNetV2가 사진을 7×7칸 × 숫자 320개로 바꿔요. 이 눈은 그대로 두고, 3단계에서 그 위만 학습해요.

      1. ① 내가 준비사진 + 정답 상자·이름무엇을 어디서 찾을지 알려 줘요.
      2. ② 미리 배운 부분 · 고정MobileNet → 7×7×320개 값같은 사진에서는 같은 특징을 뽑아요.
      3. ③ 우리가 학습할 부분특징 → 위치 + 이름 + 물체 점수내 정답과 비교해 탐지 가중치를 고쳐요.
      특징 뽑기 진행

      특징 하나를 7×7칸에 칠해 보기

      칸을 누르면 그 칸의 숫자 320개가 아래에 보여요.

      원본 40% · 특징 60%

      왼쪽은 원본, 오른쪽은 특징 색칠입니다. 화면의 겹침 비율만 바뀌며 학습에는 영향을 주지 않아요. 노란 칸은 고른 특징의 반응이 큰 곳이지, 정답 위치를 뜻하지는 않아요.

      0

      특징을 뽑으면 여기에 설명이 나옵니다.

      생각해 보기

      특징마다 반응하는 곳이 다릅니다. 어떤 특징은 동물 얼굴에, 어떤 특징은 배경에 크게 반응합니다. 사람이 “귀 모양”, “털 무늬”라고 이름 붙이지 않았는데도 이런 특징이 생겼습니다.

      찾는 부분 학습시키기

      이름마다 20%는 검증용으로 떼어 두고 나머지로 학습해요. 오차가 줄어드는 쪽으로 조금씩 고치며, 사진을 한 번 다 보면 1에폭.

      학습 설정

      첫 실험은 기본 설정 그대로 시작하세요. 오차와 예측 상자가 어떻게 바뀌는지 먼저 살펴봅니다.

      조건을 바꿔 다시 실험하기

      한 번에 한 조건만 바꾸고 아래 실험 기록을 비교하세요.

      특징 뽑기가 끝나면 학습할 수 있습니다.

      내 사진이 탐지 결과가 되기까지

      왼쪽의 사진·MobileNet 특징·정답은 같은 채로, 오른쪽 예측이 실제 학습 기록에 따라 바뀝니다. 학습이 끝나면 에폭을 움직여 비교하세요.

      내 사진고정된 특징정답 격자달라지는 예측

      ‘학습 시작’을 누르면 내 사진이 탐지 결과가 되는 과정을 여기서 볼 수 있어요.

      학습 전

      학습 중에는 최신 에폭을 따라갑니다.

      오차 (낮을수록 좋음)

      학습 사진과 검증 사진에서 정답과 다른 정도

      정답률

      상자가 정답과 절반 이상 겹치고(IoU ≥ 0.5) 종류도 맞은 비율

      ‘물체가 있다’ 점수 평균

      물체를 책임지는 칸과 배경 칸 (학습 사진)

      분류 vs 탐지 (검증 사진)

      같은 사진·같은 ‘눈’으로 이름만 맞히는 분류(티처블 머신 방식)와, 위치까지 맞히는 탐지의 정답률

      학습 중인 모델의 눈으로 본 사진

      흰 점선 = 정답 상자, 색 상자 = 지금 모델의 답(색 = 이름). 에폭마다 바뀝니다.

      실험 기록

      설정을 바꿔 다시 학습하고 비교해 보세요. 씨앗만 바꿔도 5~10% 달라지니 여러 번 해 보세요.

      번호학습률사진씨앗에폭검증 정답률(최고)마지막 오차 학습 / 검증걸린 시간
      아직 학습 기록이 없습니다.

      학습 과정 되감아 보기

      에폭을 되감아 보세요. 학습 중 생긴 특이한 현상은 ‘보러 가기’로 바로 볼 수 있어요.

      0

      검증 사진 판정표 (고른 에폭)

      그래프 다시 보기

      이름별 결과 (고른 에폭, 검증 사진)

      사진이 적은 이름은 잘 배우지 못하는 경우가 많습니다. 학습 사진 수와 정답률을 비교해 보세요.

      새 사진 판별하고 근거 보기

      새 사진을 넣고, 무엇 때문에 그 이름으로 판별했는지 봐요. 모델은 여러분이 만든 이름만 알아요.

      또는 시험 사진:
      판별에 쓸 모델

      사진은 이 기기 밖으로 나가지 않아요.

      0.15
      0.40

      왜 이 이름으로 판별했을까?

      판별을 가장 크게 움직인 숨은 값 5개

      숨은 값 × (1등 이름의 가중치 − 2등 이름의 가중치). 오른쪽(+)은 1등 쪽, 왼쪽(−)은 2등 쪽으로 민 양입니다. 사진은 그 숨은 값이 가장 크게 켜졌던 학습 사진입니다.

      숨은 값이 가장 닮은 학습 사진

      생각해 보기

      AI는 “이 사진의 숨은 값은 ○○ 사진들의 숨은 값과 닮았다”는 식으로 판단합니다. 다른 이름의 사진이 섞여 있다면 왜 헷갈렸을지 생각해 보세요.

      특징 지도

      숨은 값 32개를 2차원으로 줄인 지도(주성분 분석). 점을 가리키면 사진이 보여요.

        특징 추출: MobileNetV2 (torchvision, ImageNet 학습 가중치, BSD-3) · 브라우저 실행: ONNX Runtime Web · 탐지 머리와 학습 코드는 이 페이지에서 직접 계산합니다. [임시] 정답지의 상자는 큰 YOLO 모델로 표시한 뒤 사람이 검수했습니다.
