셀 하나 = 픽셀 하나. 숫자를 바꾸면 색이 바뀝니다.

엑셀(매크로) 버전 받기

기본 4단계

  1. 1숫자 입력

    R·G·B 시트 칸에 0~255를 쓰고 Enter

    엑셀 표를 그대로 붙여넣어도 돼요
  2. 2영역 선택

    드래그 또는 Shift+방향키

    이름 상자에 B2:F10처럼 써도 돼요
  3. 3계산

    더하기·빼기·곱하기·나누기 버튼

    250 + 50 → 255 · 빈칸은 0
  4. 4이미지 만들기

    Canvas 시트에 그림이 나와요

    다시 만들면 전·후로 나란히 비교

더 해 보기

투명도 (A 시트)
A 시트 보이기로 열어요. 0 = 투명, 255 = 불투명. 투명도 설정은 고른 영역과 같은 위치를 한 번에 채워요.
조건부 서식
숫자 크기를 색으로 보기(색조·셀 강조·데이터 막대). 만들어지는 이미지는 그대로예요.
수식 (fx)
=A1*2 · =IF(A1>128,255,0) · 다른 시트는 =R!A1*0.5. 점을 끌면 옆 칸으로 복사돼요.
셀 크기
머리글 경계를 끌어 조절해요. 작게 줄이고 색조를 주면 셀이 그림처럼 보여요.
시트 키우기
마지막 행·열에서 ↓ →로 한 줄씩, 큰 표를 붙여넣으면 그 크기로 (최대 500×500)
대비 그래프
리본 대비 › 대비 그래프: 기울기 a를 움직이면 R·G·B 숫자가 바로 바뀌어요. 칸마다 밝기(Y)를 켜면 채도 조절. 비어 있으면 예시 사진으로 시작
시트 추가
탭 옆 +로 작업용 시트를 만들어 계산하고 =시트1!A1처럼 가져와요. 탭을 오른쪽 클릭하면 이름 바꾸기·삭제
저장 · 새로 시작
Canvas 시트의 PNG로 저장 · Canvas 지우기

휴대폰·태블릿: 칸을 한 번 더 누르거나 위쪽 fx 칸에 입력하세요.

새로고침하거나 창을 닫으면 숫자가 사라져요. 남길 값은 복사해서 엑셀이나 메모장에 붙여 두세요.

체크무늬가 보이는 곳은 A값이 작아 투명해진 부분입니다. 이미지는 150×150 픽셀(가로×세로)이며 크게 확대해서 보여 줍니다.
