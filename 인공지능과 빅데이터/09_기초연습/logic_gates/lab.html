퍼셉트론

AI 뉴런은 평면에 직선을 하나 긋고, 한쪽은 1 · 다른 쪽은 0이라고 답합니다. 네 점을 모두 맞혀 보세요.

모션 해설로 보기 →

● 목표가 1인 점 · ○ 목표가 0인 점 · 빨간 점선 = 틀린 점

첫째 뉴런 h₁ (직선 1)

둘째 뉴런 h₂ (직선 2) · 출력 = h₁과 h₂가 모두 1인 곳

왜 직선 하나로는 안 될까? (식으로 보기)
  1. (0,0) → 0 이려면 b ≤ 0
  2. (1,0) → 1 이려면 w₁ + b > 0
  3. (0,1) → 1 이려면 w₂ + b > 0
  4. (1,1) → 0 이려면 w₁ + w₂ + b ≤ 0
  5. 2와 3을 더하면 w₁ + w₂ + 2b > 0, 곧 w₁ + w₂ + b > −b ≥ 0
  6. 4와 부딪힙니다. 네 조건을 모두 만족하는 값은 없습니다.
